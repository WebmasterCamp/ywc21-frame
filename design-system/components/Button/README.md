Call-to-action button — an intentional addition: the Figma source has no button yet, but the site needs "สมัครเลย" and secondary links.

**Consumer provides:** `children` (label), `variant` (`primary` gold fill | `ghost` outline), `onClick`, `disabled`.

- One `primary` per view (register / สมัคร). Everything else `ghost`.
- Labels are short Thai verbs: สมัครเลย, ดูรายละเอียด.
- Minimum height 44px; focus ring is `focus`.
