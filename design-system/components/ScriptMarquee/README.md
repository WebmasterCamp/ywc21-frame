Band of the word "human" written in many scripts, drifting slowly — the visual shorthand for Re:Humanize the Web.

**Consumer provides:** optional `words` (defaults to HOMO, 人間, 사람, ἄνθρωπος, انسان, Human, 人類, มนุษย์), `duration` in seconds (default 40), `reverse`.

- Use full-bleed directly under the Hero, and at most once more per page.
- Stack two bands with opposite `reverse` for a denser effect.
- Stops automatically under `prefers-reduced-motion`. Decorative: screen readers get only its `label`.
